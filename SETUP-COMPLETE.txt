SCHRITT 3: Erste Testseite - "So finden Sie uns" (ID: 113)
----------------------------------------

A. ALTE SEITE ANSEHEN (Elementor):
   1. Seiten → Alle Seiten
   2. Suche: "So finden Sie uns"
   3. "Mit Elementor bearbeiten" klicken
   4. IN NEUEM TAB ÖFFNEN (zum Vergleich)
   5. Jeden Abschnitt anschauen und notieren:
      - Welche Widgets werden verwendet?
      - Welche Farben/Schriften?
      - Welche Abstände?

B. NEUE SEITE ERSTELLEN (Blocks):
   1. Seiten → Neu erstellen
   2. Titel: "So finden Sie uns (BLOCKS TEST)"
   3. NICHT "Mit Elementor bearbeiten" - Block-Editor nutzen!

C. INHALTE NACHBAUEN:
   1. Öffnen Sie: C:\ND37181\scripts\widget-mapping.json
   2. Für jedes Elementor-Widget → passenden Block finden

   Beispiel-Mapping:
   ┌──────────────────────┬────────────────────────┐
   │ Elementor Widget     │ Gutenberg Block        │
   ├──────────────────────┼────────────────────────┤
   │ Heading              │ Core: Überschrift      │
   │ Text Editor          │ Core: Absatz           │
   │ Image                │ Core: Bild             │
   │ Button               │ Core: Button           │
   │ Google Maps          │ Kadence: Google Maps   │
   │ Icon List            │ Kadence: Icon List     │
   │ Columns              │ Core: Spalten          │
   └──────────────────────┴────────────────────────┘

   3. Block für Block nachbauen:
      - + klicken (Block hinzufügen)
      - Block-Name eingeben
      - Inhalt von Elementor kopieren
      - Styling anpassen (Farben, Größen, Abstände)

D. RESPONSIVE TESTEN:
   1. Im Block-Editor: Preview-Button
   2. Desktop / Tablet / Mobile ansehen
   3. Bei Bedarf anpassen

E. VERGLEICHEN:
   1. Alte Seite (Elementor-Tab)
   2. Neue Seite (Block-Editor Vorschau)
   3. Sehen sie gleich aus?

F. VERÖFFENTLICHEN:
   1. Wenn zufrieden: "Veröffentlichen" klicken
   2. Im Tracker auf "Fertig" setzen
   3. Notizen hinzufügen (z.B. "Dauer: 45 Min")
